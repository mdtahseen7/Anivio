### Anivio for Windows

- Watch and manage your library in the Windows desktop app. Sign in with the same Anivio account and profile to sync watch progress with Android.
- Spotlight and Surprise Me advance automatically while visible.
- The setup wizard uses the Anivio icon and a dimmed anime wallpaper. Install over a Windows preview to keep your profile and settings.

Download **Anivio-Windows-x64.exe** to install or upgrade. The SHA-256 checksum is attached.
